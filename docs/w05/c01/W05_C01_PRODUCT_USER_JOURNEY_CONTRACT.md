# C01 product user journey
Primary user: Production / Delivery Operations Manager.
Mode: OFFLINE / SHADOW / HUMAN-IN-THE-LOOP. No secondary persona.

case entry -> decision overview -> evidence + signals -> diagnosis + candidates
-> simulations -> deterministic recommendation -> explanation / uncertainty /
limitations -> investigation plan/evidence -> findings/conflicts/unknowns
-> investigation summary -> decision Human review -> investigation Human review
-> provenance/audit identity.

No execute/apply/schedule/purchase/quality-release action, HTTP route or UI.
Display exact source enums; retain UNKNOWN, association, conflicts and limitations.
Human comments/notes remain HUMAN_NOTE_NON_EVIDENCE, never evidence or findings.
Preserve source artifact IDs/provenance for audit and distinct Human review planes.
